# 제출물 체크리스트

현대자동차그룹 차량용 앱 개발 공모전(*Code your App into Pleos App Market*)의 제출물과 준수 사항이다. 규정이 바뀌면 공식 공지사항이 우선한다.

## 일정

```mermaid
timeline
    11.15 23:59 : 접수 마감 (기획서 + 가산점 산출물)
    11.23 : 1차 결과 (20팀)
    11.23~12.02 : 실제 동작하는 앱 완성
    12.03~04 : 2차 PT (동작하는 앱 시연)
    12.18 : 최종 10팀 발표
```

## 1차 제출물 (11.15 마감)

| # | 제출물 | 구분 | 상태 |
|---|---|---|---|
| 1 | 접수양식(기획서) DOCX | **필수** | 작성 중 |
| 2 | 시연 영상 (목업·프로토타입·화면 녹화 인정) | 가산점 | ✅ [media/deja-vroom-demo.mp4](media/deja-vroom-demo.mp4) |
| 3 | GitHub 저장소 (소스 + release APK) | 가산점 | 이 저장소. 소스·APK 업로드 예정 |
| 4 | 숏폼 (30초~1분 세로, `#HMG차량용앱개발공모전` 포함 해시태그 2~3개) | 선택 | 미정 |

APK 단독 제출은 불가하며, 저장소에 소스와 함께 올려야 한다.

## GitHub 저장소 규칙

| 항목 | 규칙 | 상태 |
|---|---|---|
| APK 위치 | 저장소 안 `apk/` 폴더 | 폴더 준비 ✅ |
| APK 파일명 | `팀명_앱이름_release.apk`, 실행 가능한 release 빌드 | 예정 |
| 용량 초과 | GitHub Releases에 올리고 Release 페이지 URL 제출 | 해당 시 |
| README 필수 4항목 | ① 앱 이름 + 한 줄 소개 ② 실행 방법 ③ 테스트 환경·필요한 설정 ④ APK 위치 또는 Release 링크 | [README](../README.md) ✅ |

## 블라인드 점검

심사 자료와 공유 링크에 개인정보·계정정보·실명이 드러나면 안 된다.

- [ ] README·문서·Discussions에 팀원 실명·연락처·소속이 없다
- [ ] 커밋 작성자가 팀 이름이다 (`git log --format='%an <%ae>'`)
- [ ] 앱 About·크레딧 화면에 실명이 없다
- [x] 영상 워터마크·자막·음성 소개에 실명이 없다
- [ ] 기획서 DOCX 작성자 메타데이터를 지웠다
- [ ] 저장소 소유 계정명이 블라인드 기준에 문제없는지 확인했다

## 준수 사항

- [ ] 순수 창작물이다. 기능을 과장하지 않는다 (미구현은 "예정"으로 표기)
- [ ] 소스, 라이브러리, 데이터, 이미지, 음원, **글꼴** 모두 사용 권한이 있다
- [ ] 오픈소스는 라이선스를 지키고 출처를 적는다 (앱 내 Open source licenses 화면 + `NOTICE`)
- [ ] 데모 데이터는 가짜 데이터다. 타인 개인정보를 쓰지 않는다
- [ ] 비밀 값(Client Secret, 서명 키)이 저장소와 APK에 없다
- [ ] 2차 PT에서 실제 동작하는 앱을 에뮬레이터로 시연한다
