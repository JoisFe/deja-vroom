# HMG/Pleos 데이터 제공 여부 문의 초안

**상태**: 준비만 함. 발송하지 않음.<br>
**목적**: FirstLook 공모전 데모에서 동일 Pleos 경로에 대응하는 도로 사진/geometry 사용 가능성을 확인한다.

## 확인할 자료

1. Pleos Connect 또는 HMG가 앱 개발자/공모전 참가자에게 제공하는 도로 전방 사진, 파노라마, 거리뷰 또는 구간 이미지 API/파트너 data가 있는지
2. 제공 가능하다면 좌표, 촬영 방향, 촬영 시점, 도로 레벨(고가/지상), 도로/route 식별자와 사용 가능한 공간 범위
3. NaviHelper가 현재 선택된 전체 route polyline/geometry와 stable route ID를 앱에 제공하는 공식 API가 있는지
4. 위 API/data의 Playground SDK project eligibility, 신청 절차, 지원 차량/Emulator 조건 및 예상 승인 기간
5. Pleos 차량 디스플레이, WebView, overlay, attribution, caching, 공모전 시연/영상, 제출 APK/공개 GitHub에 적용되는 표시·저장·배포 권한
6. Demo path가 바뀌거나 route reroute가 발생할 때 사진의 route matching을 검증할 공식 식별 값 또는 권장 방식

## 답변 기록 양식

| 질문 | 답변 요약 | 출처/담당 부서 | 확인일 | 승인·사용권 범위 | 후속 조치 |
|---|---|---|---|---|---|
| 1-6 | 답변 대기 | 미발송 | - | 미확인 | 사용자 발송/승인 후 기록 |

발송을 위해 contest portal, 계정 또는 수신자를 자동으로 조작하지 않는다. 사용자가 공식 담당 채널과 project access를 확인한 후 전달할 수 있도록 질문만 준비했다.
